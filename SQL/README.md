# 🗄️ SQL Analysis

## 📌 Overview

This folder contains SQL queries used to analyze the EV Charging Network dataset. The analysis focuses on charging sessions, revenue, energy consumption, vehicle types, payment methods, and business performance.

---

## 🎯 Business Objective

The goal of this SQL analysis is to answer important business questions that help improve operational efficiency, understand charging behavior, and support business decision-making.

- Top 3 Energy Consuming Cities

### Advanced SQL

- City Revenue using CTE

---

## 💡 Key Business Insights

- Delhi generated the highest revenue.
- Delhi recorded the highest energy consumption.
- Truck charging sessions were the highest.
- Cash was the most preferred payment method.
- Peak charging hours were identified using charging start time.
