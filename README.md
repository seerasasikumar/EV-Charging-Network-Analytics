# ⚡ EV Charging Network Analytics

A comprehensive Data Analytics project that analyzes Electric Vehicle (EV) charging station performance using **Excel, SQL, Python, and Power BI**.

The project provides insights into charging sessions, revenue generation, energy consumption, vehicle usage, payment methods, and peak charging hours to support business decision-making.

---

# 📌 Project Overview

Electric Vehicle adoption is increasing rapidly, making efficient charging infrastructure essential.

This project analyzes EV charging station data to answer important business questions such as:

- Which city generates the highest revenue?
- Which vehicle type uses charging stations the most?
- Which payment method is preferred?
- What are the peak charging hours?
- Which cities consume the highest energy?

---

# 💡 Key Business Insights

- ✅ Delhi generated the highest revenue.

- ✅ Trucks had the highest charging sessions.
- ✅ Cash was the most preferred payment method.
- ✅ Peak charging activity occurred at **6 AM**.
