# EV Charging Network Analytics

---

# 📌 Project Summary

The EV Charging Network Analytics project is a complete end-to-end Data Analytics solution developed using Excel, SQL, Python, and Power BI.

The project transforms raw EV charging station data into meaningful business insights through data cleaning, analysis, visualization, and interactive dashboards.

---

# 🎯 Project Objectives

The primary objectives of this project are:

- Analyze charging station performance
- Monitor revenue generation
- Measure energy consumption
- Identify customer payment preferences
- Analyze charging demand by vehicle type
- Detect peak charging hours
- Support business decision-making

# 💡 Key Findings

- Delhi generated the highest revenue.
- Delhi consumed the highest energy.
- Trucks recorded the highest charging sessions.
- Cash was the most preferred payment method.
- Peak charging demand occurred at 6 AM.

---

# 📊 Business Recommendations

- Expand charging stations in Delhi.
- Install additional fast chargers in high-demand cities.
- Increase infrastructure for commercial vehicles.
- Encourage digital payments through promotional offers.
- Allocate additional staff during peak charging hours.
