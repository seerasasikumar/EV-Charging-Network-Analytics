# 📂 Dataset

## 📌 Overview

This folder contains the dataset used for the EV Charging Network Analytics project.

---

## 📄 Dataset Information

**Dataset Name:** EV_Charging_Station.csv

This dataset contains charging session details from Electric Vehicle charging stations across multiple cities. It includes information about charging time, energy consumption, charging cost, vehicle type, and payment method.

---

## 📊 Features

- Station ID
- City
- Date
- Vehicle Type
- Charging Start Time
- Charging End Time
- Energy Consumed (kWh)
- Charging Cost (INR)
- Payment Method

---

## 🎯 Purpose

The dataset is used to perform:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Excel Analysis
- SQL Analysis
- Power BI Dashboard Development
- Business Insights Generation

---

Educational dataset created for portfolio and analytics practice.
